ข้อที่ 1

การคำนวณพื้นที่วงกลม

กระบวนการรับค่ารัศมีเพื่อนำมาคำนวณหาพื้นที่ของวงกลมด้วยสูตรทางคณิตศาสตร์

// Pseudocode: การคำนวณพื้นที่วงกลม
BEGIN
    INPUT radius
    SET PI = 3.14159
    SET area = PI * radius * radius
    OUTPUT "Area of the circle is: " + area
END
ข้อที่ 2

การคำนวณเกรด (Grading System)

การใช้เงื่อนไขตรวจสอบคะแนนแบบหลายชั้น (Nested-If) เพื่อประเมินระดับผลการเรียน

// Pseudocode: การคำนวณเกรด
BEGIN
    INPUT score
    IF score >= 80 THEN
        SET grade = "A"
    ELSE IF score >= 70 THEN
        SET grade = "B"
    ELSE IF score >= 60 THEN
        SET grade = "C"
    ELSE IF score >= 50 THEN
        SET grade = "D"
    ELSE
        SET grade = "F"
    ENDIF
    OUTPUT "Your grade is: " + grade
END
ข้อที่ 3

การหาค่าสูงสุดจากตัวเลข 3 จำนวน

อัลกอริทึมเปรียบเทียบชุดข้อมูลเพื่อคัดเลือกค่าที่มากที่สุดมาแสดงผล

// Pseudocode: การหาค่าสูงสุดใน 3 จำนวน
BEGIN
    INPUT num1, num2, num3
    SET max_value = num1
    
    IF num2 > max_value THEN
        SET max_value = num2
    ENDIF
    
    IF num3 > max_value THEN
        SET max_value = num3
    ENDIF
    
    OUTPUT "The maximum value is: " + max_value
END
